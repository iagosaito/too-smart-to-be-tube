# Landing page

Static presentation site for Too Smart To Be Tube: plain HTML, CSS and a small script, with no build step and no
third-party requests (fonts, analytics or CDNs), matching the extension's privacy promise.

- Preview: open `site/index.html` in a browser.
- Deploy: GitHub Pages (Settings → Pages → *GitHub Actions* or a branch with this folder), Netlify, or any
  static host.
- Screenshots in `assets/` come from the real extension code rendered with **fictional channels and generated
  thumbnails**, so the site ships no third-party content.
